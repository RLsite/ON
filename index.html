        🤖 בחירת מודל
        
      

      
המודל שנבחר כאן הוא המודל שמבצע את בדיקות ה-QA. שמו משויך אוטומטית (שדה agent) לכל בדיקה חדשה שנשלחת מ"➕ בקשה חדשה", כדי שיתועד איזה מודל טיפל בה. אפשר לבחור מודל מובנה (Claude) או להוסיף מודל חיצוני (Gemini / OpenAI / OpenRouter / NVIDIA וכל API תואם).

      
      

        
—

        
        
        
      

      
אם הוגדר דפדפן מקומי (🖥️ Preview) + כתובת אתר: לוחץ ומבצע בדיקה חיה עם לחיצות על הבדיקה הפתוחה הראשונה — המודל מנווט, לוחץ, ממלא, ומכריע PASS/FAIL, ורואים את זה חי בשרשור. בלי דפדפן מקומי: נסוג לניתוח מהיר (בלי לחיצות). אפשר גם ▶️ על כל בדיקה ספציפית.

      
      

      

      
      
      
      
      
      

        
        
        
דוגמאות: https://api.openai.com/v1 · https://openrouter.ai/api/v1 · https://integrate.api.nvidia.com/v1

      

      
      
      
      
      
      

        
        
      

      

      

        איך המודל מתחיל / נעצר לעבוד?

        המודל לא "מופעל" מהחלון הזה — הדשבורד הוא תור העבודה, והמודל מושך ממנו:

        • מודל מובנה (Claude): סשן Claude Code מושך את התור. הטריגר להתחיל = לומר לו בצ'אט "עבוד על תור ה-QA" (או /loop 5m לריצה מתמשכת). לעצור = כפתור 🚩 עצור לולאה, או עצירת הסשן.

        • מודל חיצוני: "בדוק חיבור" מוודא שהמפתח וה-API תקינים. הרצה בפועל על התור נעשית ע"י סקריפט/סוכן שמושך את ה-API (ראה ℹ️ API) — הדגל 🚩 עוצר גם אותו.

        בקיצור: בחירת מודל = מי יעבוד ובאיזה שיוך; התור + הדגל 🚩 = מתי להתחיל ולעצור.
      

    

  


  

    

      

        🔗 חיבור GitHub
        
      

      

        
        
        
      


      

        
חיבור לריפו GitHub — לצפייה ב-issues פתוחים הקשורים לבדיקות, וליצירת issue ישירות מבדיקה שנכשלה (FAIL).

        
        
        
        
        
        
        
        

        
✓ טוקן שמור — לא צריך להזין שוב

        

          
          
          
          
        

        

        

        
        
—

      


      

        
        
נתיב לתיקיית הקוד של הפרויקט על הדיסק (למשל של אלון). כשמוגדר, הרצת המודל החיצוני תכלול את מבנה הקבצים ותוכן קבצים רלוונטיים — כדי שיבצע ניתוח קוד אמיתי, לא רק ניחוש. מהיר יותר מ-GitHub ותמיד עדכני.

        

          
          
        

        

        

          
          
        

      


      

        
        
כתובת האפליקציה לבדיקה (למשל https://alon.rlapp.net או http://localhost:3000). כשמוגדר, הכלי טוען את הדף ב-Chrome המקומי שלו וקורא DOM + שגיאות קונסול + בקשות שנכשלו — מצב הדף החי מוזן למודל (בדיקה דינמית, בלי תלות בסשן Claude).

        
        

          
          
        

        

        
        
הכלי יכול להפעיל את האפליקציה מקומית לבדיקה — בלי לגעת באתר החי. הזן תיקייה ופורט (ברירת מחדל: אלון על 2500), לחץ הפעל, והכתובת לבדיקה מתעדכנת אוטומטית. הערה: שרת סטטי — ה-functions של Cloudflare (API צד-שרת) לא ירוצו; ה-UI והזרימות כן.
