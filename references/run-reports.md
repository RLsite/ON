# דוחות הרצה, Release Checklist ומדדי QA

מתי להשתמש: בסוף סבב בדיקות (כמה checks נסגרו ברצף), לפני deploy/release, או כשהמשתמש
מבקש "סיכום מצב הבדיקות".

## דוח הרצה (Test Run Report) — מופק מנתוני הדשבורד

הנתונים כבר בתור (`GET /api/state`) — הדוח הוא סיכומם:

```markdown
# דוח הרצת בדיקות — <תאריך> · <גרסה שנבדקה>
| מדד | ערך |
|---|---|
| תרחישים שהורצו | N (מזהים #a–#b) |
| PASS / FAIL / Partial | x / y / z |
| אחוז הצלחה | pass/(pass+fail) |
| באגים חדשים | רשימת ה-FAILs עם severity |
| Critical/High פתוחים | N (חוסם release אם >0 Critical) |
| לא הורץ/חסום | checks ב-partial + הסיבה |

## פירוט FAILs
- #NN <כותרת> — <severity/priority> — <שורת סיכום>

## הערות הרצה
סביבה, גרסה, מה לא כוסה והצטבר לחוב בדיקות (test debt).
```

חשוב: דוח עם 100% PASS מחייב שורת הסתייגות — אילו ניסיונות שבירה בוצעו (כלל 4c),
אחרת הדוח מטעה. "הכול עבר" בלי negative testing = "לא באמת בדקנו".

## Release Checklist (קריטריוני יציאה לפני deploy)

- [ ] כל התרחישים הקריטיים (P1/P2 בתוכנית) הורצו — לא רק "נפתחו"
- [ ] אפס באגים Critical פתוחים; High פתוחים — רק עם אישור מפורש של המשתמש
- [ ] Regression על אזורים שהשתנו + הצמודים להם (ripple — כלל 4b)
- [ ] Smoke על האתר החי אחרי ה-deploy עצמו (לא רק לפני)
- [ ] בדיקה בדפדפן/רזולוציה נוספים לפחות לזרימה המרכזית
- [ ] אין שגיאות קונסול חדשות בדפים הראשיים
- [ ] גיבוי/שחזור נתונים נבדק אם הגרסה נוגעת באחסון
- [ ] מספר גרסה עודכן ומופיע נכון באתר

## מדדי QA (KPIs) — מה למדוד ומה המשמעות

| מדד | חישוב | אזהרת פירוש |
|---|---|---|
| Pass rate | pass/(pass+fail) | גבוה מדי (100%) = בדיקות רדודות, לא איכות |
| Defect density | באגים למודול | מצביע איפה למקד בדיקות, לא "מי אשם" |
| Escape rate | באגים שהמשתמש מצא / סה"כ | המדד האמיתי של איכות ה-QA — כל דיווח משתמש בפורום שהיה אמור להיתפס כאן נספר |
| Reopen rate | תיקונים שנכשלו ב-retest | גבוה = תיקונים חפוזים או retest רדוד |
| כיסוי מודולים | מודולים עם checks / כלל המודולים | חורים בכיסוי לפי שדה module בדשבורד |

ה-KPI בדשבורד (📊) כבר מציג pass rate, FAILs, Critical פתוחים — הדוח המילולי מוסיף
את ההקשר: מה כוסה, מה לא, ומה המסקנה המעשית (לשחרר / לתקן קודם).
