# ON TracK

Web workspace for model-driven project control.

## What this is
ON TracK is a local-first web tool for:
- connecting a chosen model
- connecting a GitHub repository
- planning work
- approving actions before execution

## Run locally
```bash
npm start
```

## Main files
- `index.html` - app shell and UI
- `server.js` - local web server and API
- `PROJECT_INFO.md` - current project status and steps
